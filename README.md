1. INTRODUCTION

The Workshop Tool Inventory and Maintenance Management System is a Python-based application developed to improve the management of tools and equipment in technical workshops.

The system provides an organised way to register tools, monitor available quantities, record issued and returned equipment, monitor tool conditions, and track maintenance schedules.

2. PROBLEM STATEMENT

Many technical workshops experience difficulties keeping accurate records of their tools and equipment. Manual record keeping can lead to misplaced tools, poor inventory control, delayed maintenance, and difficulty identifying unavailable equipment.

This project provides a simple digital solution to improve workshop inventory management and maintenance monitoring.

3. AIM AND OBJECTIVES

The aim of this project is to develop a simple Python application for managing workshop tools and equipment.

The objectives are to:

1. Register workshop tools with unique identification numbers.
2. Monitor the total and available quantities of tools.
3. Record tools issued to workshop users.
4. Record returned tools.
5. Monitor the physical condition of equipment.
6. Generate alerts for low-stock tools.
7. Track maintenance and servicing schedules.
8. Generate inventory and usage reports.

4. SYSTEM FEATURES

- Tool registration and identification.
- Tool issuing and return management.
- Inventory quantity monitoring.
- Equipment condition monitoring.
- Low-stock notifications.
- Maintenance schedule tracking.
- Workshop usage reports.
- CSV report export.

5. PROGRAMMING LANGUAGE AND CONCEPTS

The project was developed using Python.

The following programming concepts were applied:

- Variables and data types.
- Functions.

- Conditional statements.
- Loops.

- Input validation.

6. SYSTEM REQUIREMENTS

- Python 3.8 or later.

No external Python packages are required.

7. HOW TO RUN THE PROGRAM

1. Download or clone the project repository.

2. Open the project folder.

3. Open a terminal or command prompt.

4. Run the following command:
   
   "python workshop_tool_management.py"

5. Select an option from the displayed menu.

6. Follow the instructions to manage workshop tools.

10. CONCLUSION

The Workshop Tool Inventory and Maintenance Management System demonstrates how Python programming can be used to solve practical problems in technical workshop management.

The project provides an organised approach to tool inventory control, equipment monitoring, and preventive maintenance.
